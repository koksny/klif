# Contributing

This repo is the public snapshot of KLIF. Issues and PRs that stay on that scope are welcome.

## Ground rules

- No model weights, no compiled HIP/Vulkan runtimes, no logs, no secrets.
- Paths in examples should be relative or clearly fictional (`D:\models\…`), never a contributor's real home directory.
- Bind examples to `127.0.0.1` unless the change is explicitly about LAN serving.
- Read [docs/publish.md](docs/publish.md) if you are promoting code from a private tree.
